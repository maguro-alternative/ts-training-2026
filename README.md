# TypeScript研修 - Day 3 演習リポジトリ

Day 1〜2で学んだ型の知識を、実際に手を動かして定着させる日です。
用意された8つの課題を順に解いていってください。

## セットアップ

```bash
npm install
```

Node.js 20以上を推奨します。

## 進め方

### 1. 進捗画面を開く(推奨)

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開くと、各課題の進捗が一覧で見られます。

### 2. 課題を解く

`src/exercises/` 配下のフォルダを **番号順** に進めてください。

各フォルダには以下のファイルがあります:

- `README.md` — 課題の説明
- `index.ts` — あなたが編集するファイル (`any` やTODOを書き換える)
- `index.test.ts` — 自動判定用のテスト (**基本的に編集しない**)

### 3. テストを実行して判定する

```bash
# 全課題のテストを実行
npm test

# 特定の課題だけ実行
npm test 01-basic-types

# 編集するたびに自動実行(おすすめ)
npm run test:watch
```

`npm test` を実行すると `public/test-results.json` が更新され、
ブラウザの進捗画面にも反映されます(ページを再読み込み、または少し待つと自動更新)。

## ルール

- **`any` の使用は禁止** (Day 2で学んだ通り、具体的な型に置き換える)
- **`// @ts-ignore` / `// @ts-expect-error` で型エラーを握りつぶすのも禁止**
  (ただしテストファイル内の `@ts-expect-error` は判定のためのものなので触らない)
- **テストファイルは編集しない** (仕様書として読むのはOK)
- **分からなくても5分は自力で考える**。その後で講師やペアに質問する
