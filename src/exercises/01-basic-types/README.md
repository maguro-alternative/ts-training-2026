# 課題 01: 基本型を付ける

## 目的
- `any` の危うさを体感する
- プリミティブ型、配列型、オブジェクト型を自分の手で書く
- `type` エイリアスで型を定義する

## 進め方
1. このフォルダの `index.ts` を開く
2. `any` と書かれている箇所を適切な型に置き換える
3. ターミナルで以下を実行

```bash
npm test 01-basic-types
```

4. すべて緑になればクリア

## ルール
- **`any` 禁止** (見つけたら具体的な型に直す)
- `// @ts-ignore` / `// @ts-expect-error` で型エラーを握りつぶさない
- テストファイル (`index.test.ts`) は **編集しない**

## ヒント
- プリミティブ型: `string`, `number`, `boolean`
- 配列: `number[]` または `Array<number>`
- オブジェクト型は `type User = { name: string; age: number }` のように書く
- 関数は `function f(a: number): number` のように引数と戻り値に型を付ける

## 詰まったら
- エラーメッセージの **1行目だけでなく最後まで** 読むこと
- VSCode なら関数名にカーソルを合わせると推論された型が見える
