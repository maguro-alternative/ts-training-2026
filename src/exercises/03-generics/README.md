# 課題 03: ジェネリクス

## 目的
- なぜジェネリクスが必要か (`any` との違い) を体感する
- 関数にジェネリクスを付けられる
- `extends` による型パラメータの制約を使える

## 進め方
1. `index.ts` の TODO を埋める
2. `npm test 03-generics` が全て緑になればクリア

## ヒント
- `function first<T>(arr: T[]): T | undefined` のように型パラメータを書く
- 「オブジェクトの特定のキーだけ取り出す」ような関数は `K extends keyof T` の制約が必要
- `any` を使うと型情報が失われるので NG。ジェネリクスなら呼び出し側の型が保たれる

## 詰まったら
- 「引数の型から戻り値の型が決まる」関数が作れれば OK
- 戻り値を決めるために `keyof T` や `extends` の制約が必要になることがある
