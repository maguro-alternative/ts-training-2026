# 課題 05: `any` リファクタリング

## 目的
- 実務で遭遇する「`any` だらけのコード」を `strict` で通るように直す
- 型エラーメッセージを読んで適切な型を推測する
- Day 1〜4で学んだ知識を総動員する

## 進め方
1. `index.ts` に書かれたコードを読む (動くが型は雑)
2. `any` を全て具体的な型に置き換える
3. `npm test 05-refactor-any` が緑になればクリア

## ルール
- ロジック (関数の中身) は **基本的に変えない**
- ただし型を正しくするために必要なら、`as` アサーションや型ガード追加などは OK
- 最終的にファイル内に `any` が1つも残らないことがゴール

## ヒント
- まず `npm run typecheck` でエラーを出してみる
- エラーが多すぎる場合は、ファイル上から順に直していく
- わからない関数の型は VSCode でホバーすると推論されたヒントが出る

## 詰まったら
- `unknown` を使うべきか `T extends ...` にすべきか迷ったら:
  - 外部から来るデータ → `unknown`
  - 汎用関数の入力 → ジェネリクス
